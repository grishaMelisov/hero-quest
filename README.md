# Hiro Quest — Колесо Фортуны

Тестовое задание: верстка страницы «Квесты» для сервиса **HiroVPN** по макету Figma.

**Деплой:** https://grishamelisov.github.io/hero-quest/#/account

---

## Стек

| Технология | Описание |
|---|---|
| React 19 + TypeScript | UI и типизация |
| Vite 8 | Сборщик |
| Tailwind CSS v4 | Стилизация (CSS-only конфиг) |
| Framer Motion | Анимация барабана |
| React Router v7 | HashRouter-навигация |
| vite-plugin-svgr | SVG как React-компоненты |

---

## Что реализовано

### Колесо Фортуны
Горизонтальный барабан с карточками-призами. Анимация выполнена через `useAnimation` + `motion.div` из Framer Motion:
- Бесконечная лента из 12 копий набора карточек
- Разгон и плавное торможение (кривая инерции рулетки)
- Победитель всегда останавливается строго по центру статичного индикатора
- Конфетти и модальное окно с выигрышем

### Квесты
Сетка квест-карточек с прогресс-баром. Квесты кликабельны — открывается модальное окно с деталями и кнопкой выполнения.

### Стрик дней
Визуальная шкала серии дней подряд.

### Таймер
После прокрутки барабана запускается обратный отсчёт до следующей попытки.

## Как запустить

```bash
npm install
npm run dev
```

Открыть: http://localhost:5173

---

## Как запустить Колесо Фортуны

Кнопка **«ИСПЫТАТЬ УДАЧУ»** заблокирована до тех пор, пока не выполнены все квесты на странице.

1. Нажмите на любой квест в сетке
2. В модальном окне нажмите кнопку выполнения
3. Повторите для всех квестов
4. После выполнения последнего квеста кнопка разблокируется — жмите и крутите
